# Assets

- `characters/humans/` – Quaternius Universal Base Characters and Universal
  Animation Library (CC0), retargeted to Godot's humanoid skeleton. Every
  fighter is built from these at runtime (`scripts/characters/`).
- `fonts/` – VT323 (SIL OFL 1.1) for the terminal-style interface.
- `licenses/` – license texts that must ship with the assets.
- `source_assets/` – original downloads, ignored by Godot and Git.

Board patterns, profile symbols, outfits and effects are generated in code;
there are no texture files. See [THIRD_PARTY_ASSETS.md](../THIRD_PARTY_ASSETS.md).
